# Noren

Omarchy plugin that drives Chromium from the shell: url-bar overlay, tab search,
and chrome-less Hyprland windows. Plugin id `io.github.keithnyc.noren`.

**Read `DEVELOPMENT.md` first.** It carries the architecture, the design
decisions and why they were made, the environment facts that cost real debugging
time, and the list of bugs already fixed. Most questions are answered there.

## Before changing anything

**Three reload paths. Forgetting one looks exactly like "the fix didn't work".**

| changed | needs |
|---|---|
| `*.qml` | `omarchy-restart-shell` |
| `host/noren-host` | cycle the host — kill it by PID; the extension reconnects |
| `extension/*.js` | bump the filename (`background-N.js` + `manifest.json`), restart the browser, **and** Reload in `chrome://extensions` |

Before diagnosing anything, run `./bin/noren doctor`. It checks the whole chain
without needing the bridge and decodes Chromium's `disable_reasons` by name. It
exists because a four-round misdiagnosis would have been one command. Extend it
rather than debugging by hand.

## Invariants

- **Do not fork Chromium.** See DEVELOPMENT.md for what a fork would actually buy
  and why it is not worth it.
- **Enter opens a new window; Ctrl+Enter replaces the current page.** Enter must
  never mutate the window behind the overlay — that was tried and rejected.
- **Only peel tabs in `type === "normal"` windows,** or auto-peel destroys every
  window Noren creates.
- **Never commit `host/noren-extension.pem`.** Private key, per machine,
  generated by `install.sh` and mirrored to `~/.local/share/noren/`, from which
  a fresh clone restores it so the extension id stays stable.
  `extension/manifest.json` is generated too — edit `manifest.json.template`.
- **`pgrep -f` / `pkill -f` with a path pattern kills this shell.** Use explicit
  PIDs or `-x`.

## Testing

Verify against the real system rather than assuming — most of this project's
bugs were invisible in the code and obvious in `hyprctl clients`,
`/proc/<pid>/cmdline`, or the browser's `Preferences`. Let keith drive
interactive testing; the overlay and window behaviour can't be judged from here.
